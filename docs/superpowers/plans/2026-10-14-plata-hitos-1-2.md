# Plata — Hitos 1 y 2: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir el esqueleto multiplataforma de Plata (host nativo + motor OpenSilver en WebAssembly) y probar que una aplicación Silverlight **ya compilada** (`.xap`) corre **sin recompilar**.

**Architecture:** Un host nativo .NET (Photino.NET) abre una ventana con el WebView del sistema y sirve los archivos del motor por un esquema propio `plata://` (sin servidor HTTP local). Dentro del WebView corre el motor, compilado a WebAssembly con OpenSilver. El motor abre el `.xap` en memoria, reescribe las referencias de sus librerías de Silverlight a OpenSilver con Mono.Cecil, y arma las pantallas con el lector de XAML en tiempo de ejecución de OpenSilver.

**Tech Stack:** .NET 10 SDK (con workload `wasm-tools`); Photino.NET 4.0.16; OpenSilver 3.3.3 y OpenSilver.WebAssembly 3.3.3; Mono.Cecil 0.11.6; xUnit; Playwright (.NET) para probar el motor sin ventana; GitHub Actions (Linux, macOS, Windows).

**Spec:** `docs/superpowers/specs/2026-10-14-plata-design.md`

## Global Constraints

- **Alcance de estos hitos:** solo el reproductor genérico y apps de prueba **propias**. No se incluye nada específico de una institución (modo portal, suplantación de identificador de navegador, descarga de apps de terceros, uso de sesiones ajenas). Eso vive en hitos posteriores y requiere autorización de la institución.
- **Licencia:** MIT. Cada archivo de código nuevo lleva la cabecera MIT del proyecto.
- **`.xap` reales nunca de terceros.** `tests/corpus/` solo contiene apps Silverlight con licencia abierta o creadas en este repositorio. `.gitignore` excluye `*.xap` fuera de `tests/corpus/`.
- **Versiones exactas (pisos):** .NET `net10.0`; Photino.NET `4.0.16`; OpenSilver `3.3.3`; OpenSilver.WebAssembly `3.3.3`; Mono.Cecil `0.11.6`.
- **Linux necesita `libwebkit2gtk-4.1.so.0`.** Photino.Native 4.x enlaza esa versión; la 3.x enlaza `webkit2gtk-4.0`, ausente en distribuciones nuevas. Por eso el piso es Photino 4.
- **El motor se sirve solo por el esquema `plata://`.** No se levanta ningún servidor HTTP local (`WebAssembly.DevServer` no se usa en producción).
- **Nombre e imagen:** Plata se presenta como "compatible con aplicaciones Silverlight"; no usa la marca ni el logo de Microsoft como propios.

## Review Focus

Entradas que el diseño implica pero que ningún otro test ejercita, de más a menos probable que rompan a una persona:

- **`.xap` dañado o que no es un ZIP.** El Cargador debe dar un error claro (`PlataXapInvalidoException`), no una excepción de ZIP cruda. Test en Task 4.
- **`AppManifest.xaml` sin `EntryPointAssembly` o `EntryPointType`.** Manifiesto válido como XML pero incompleto. Debe fallar con un mensaje que nombre el campo faltante. Test en Task 4.
- **Ruta con `..` o absoluta en el esquema `plata://`.** El servidor de archivos no debe salir de la carpeta del motor (travesía de directorios). Test en Task 2.
- **Librería sin referencias a Silverlight (ya de .NET moderno).** El Traductor debe devolverla intacta, sin romperla. Test en Task 5.
- **XAML con un evento (`Click="X"`) cuyo método no existe en la clase.** El Cargador de pantallas debe reportarlo en el informe, no caerse. Test en Task 6.

Dos decisiones de frontera:

    {
        [".html"] = "text/html", [".js"] = "text/javascript", [".mjs"] = "text/javascript",

    public static string Para(string ruta)

- [ ] **Step 4: Implementar `ServidorDeArchivos`**

```csharp
namespace Plata.Host;

public sealed class ServidorDeArchivos(string raiz)
{
    private readonly string _raiz = Path.GetFullPath(raiz);

    public Stream? Resolver(string url, out string contentType)
    {
        contentType = "text/plain";
        var uri = new Uri(url);
        var rel = Uri.UnescapeDataString(uri.AbsolutePath).TrimStart('/');
        if (rel.Length == 0) rel = "index.html";
        var destino = Path.GetFullPath(Path.Combine(_raiz, rel));
        // Defensa contra travesía: el destino debe quedar dentro de la raíz.
        if (!destino.StartsWith(_raiz + Path.DirectorySeparatorChar, StringComparison.Ordinal)
            && destino != _raiz)
            return null;
        if (!File.Exists(destino)) return null;
        contentType = TiposDeContenido.Para(destino);
        return File.OpenRead(destino);
    }
}
```

public class XapReaderTests

    private static Stream HacerXap(string manifest, params (string, byte[])[] extra)
    {
        var ms = new MemoryStream();
        using (var z = new ZipArchive(ms, ZipArchiveMode.Create, leaveOpen: true))
        {

`XapReader.cs`:
```csharp
using System.IO.Compression;
using System.Xml.Linq;

namespace Plata.Motor.Xap;

public sealed class PaqueteXap
{
    public required AppManifest Manifest { get; init; }
    public required IReadOnlyDictionary<string, byte[]> Entradas { get; init; }

    public byte[] Assembly(string nombreSinExtension)
    {
        var part = Manifest.Parts.FirstOrDefault(p =>
            Path.GetFileNameWithoutExtension(p.Source)
                .Equals(nombreSinExtension, StringComparison.OrdinalIgnoreCase));
        var clave = part?.Source ?? nombreSinExtension + ".dll";
        if (!Entradas.TryGetValue(clave, out var bytes))
            throw new PlataXapInvalidoException($"El .xap no contiene la librería '{clave}'.");
        return bytes;
    }
}

public static class XapReader
{
    private static readonly XNamespace D = "http://schemas.microsoft.com/client/2007/deployment";

    public static PaqueteXap Leer(Stream xap)
    {
        Dictionary<string, byte[]> entradas = new(StringComparer.OrdinalIgnoreCase);
        try
        {
            using var zip = new ZipArchive(xap, ZipArchiveMode.Read);
            foreach (var e in zip.Entries)
            {
                using var s = e.Open();
                using var ms = new MemoryStream();
                s.CopyTo(ms);
                entradas[e.FullName.Replace('\\', '/')] = ms.ToArray();
            }
        }
        catch (InvalidDataException ex)
        {
            throw new PlataXapInvalidoException("El archivo no es un .xap válido (no es un ZIP).", ex);
        }

        if (!entradas.TryGetValue("AppManifest.xaml", out var manBytes))
            throw new PlataXapInvalidoException("El .xap no tiene AppManifest.xaml.");

        var manifest = LeerManifiesto(manBytes);
        return new PaqueteXap { Manifest = manifest, Entradas = entradas };
    }

    private static AppManifest LeerManifiesto(byte[] bytes)
    {
        XDocument doc;
        try { doc = XDocument.Load(new MemoryStream(bytes)); }
        catch (Exception ex) { throw new PlataXapInvalidoException("AppManifest.xaml no es XML válido.", ex); }

        var root = doc.Root ?? throw new PlataXapInvalidoException("AppManifest.xaml está vacío.");
        string Req(string attr) => (string?)root.Attribute(attr)
            ?? throw new PlataXapInvalidoException($"AppManifest.xaml no tiene el atributo '{attr}'.");

        var parts = root.Element(D + "Deployment.Parts")?.Elements(D + "AssemblyPart")
            .Select(p => new AssemblyPart((string?)p.Attribute("Source") ?? ""))
            .Where(p => p.Source.Length > 0).ToList() ?? new List<AssemblyPart>();

        return new AppManifest(Req("EntryPointAssembly"), Req("EntryPointType"),
            (string?)root.Attribute("RuntimeVersion") ?? "", parts);
    }
}
```

`ReferenceRetargeter.cs`:
```csharp
using Mono.Cecil;

namespace Plata.Motor.Puente;

public sealed class ReferenceRetargeter
{
    public byte[] Traducir(byte[] ensamblado, out IReadOnlyList<string> referenciasReescritas)
    {
        var reescritas = new List<string>();
        using var mod = ModuleDefinition.ReadModule(new MemoryStream(ensamblado));

        // Evita duplicar OpenSilver si ya hay que redirigir varias a la misma.
        var yaOpenSilver = mod.AssemblyReferences.Any(a => a.Name == "OpenSilver");

        foreach (var r in mod.AssemblyReferences.ToList())
        {
            var destino = MapaDeEnsamblados.Destino(r.Name);
            if (destino == null) continue;
            reescritas.Add(r.Name);
            if (destino == "OpenSilver" && (yaOpenSilver || reescritas.Count(x => MapaDeEnsamblados.Destino(x) == "OpenSilver") > 1))
            {
                mod.AssemblyReferences.Remove(r);
                continue;
            }
            r.Name = destino;
            r.PublicKeyToken = Array.Empty<byte>();
            r.Version = new Version(3, 3, 3, 0);
            yaOpenSilver = true;
        }

        // Redirige también las referencias de tipo (TypeReference.Scope) que apuntaban
        // a las referencias eliminadas, hacia la que quedó con destino OpenSilver.
        var osRef = mod.AssemblyReferences.FirstOrDefault(a => a.Name == "OpenSilver");
        if (osRef != null)
            foreach (var t in mod.GetTypeReferences())
                if (t.Scope is AssemblyNameReference an && MapaDeEnsamblados.Destino(an.Name) == "OpenSilver" && an.Name != "OpenSilver")
                    t.Scope = osRef;

        using var salida = new MemoryStream();
        mod.Write(salida);
        referenciasReescritas = reescritas;
        return salida.ToArray();
    }
}
```

```csharp
using System.Reflection;
using System.Xml.Linq;
using System.Windows.Markup;
using Plata.Motor.Informe;

namespace Plata.Motor.Pantallas;

public sealed class CargadorDePantallas(InformeDeCompatibilidad informe)
{
    public void Cargar(object pantalla, string xaml)
    {
        try
        {
            // OpenSilver aplica el XAML sobre la instancia existente y conecta eventos por nombre.
            XamlReader.Load(xaml, pantalla);   // sobrecarga de OpenSilver con RootObjectInstance
        }
        catch (Exception ex)
        {
            informe.Anotar("xaml", ex.Message);
            throw;
        }
        VerificarEventos(pantalla, xaml);
    }

    // Segunda pasada: cada atributo de evento del XAML debe tener su método en el tipo de la pantalla.
    private void VerificarEventos(object pantalla, string xaml)
    {
        var tipo = pantalla.GetType();
        var metodos = tipo.GetMethods(BindingFlags.Instance | BindingFlags.Public | BindingFlags.NonPublic)
            .Select(m => m.Name).ToHashSet(StringComparer.Ordinal);

        foreach (var el in XDocument.Parse(xaml).Descendants())
            foreach (var attr in el.Attributes())
            {
                var v = attr.Value;
                // Un evento se referencia por el nombre de un método existente, no una URI ni un binding.
                if (attr.IsNamespaceDeclaration || v.Contains('{') || v.Contains('/') || v.Contains(' ')) continue;
                if (EsNombreDeEvento(el.Name.LocalName, attr.Name.LocalName) && !metodos.Contains(v))
                    informe.Anotar("evento", $"{el.Name.LocalName}.{attr.Name.LocalName}=\"{v}\" (método {v} ausente)");
            }
    }

    // Lista de nombres de evento conocidos de Silverlight usados en estos hitos.
    private static readonly HashSet<string> Eventos = new(StringComparer.Ordinal)
    { "Click", "Loaded", "SelectionChanged", "TextChanged", "Checked", "Unchecked", "MouseLeftButtonDown" };

    private static bool EsNombreDeEvento(string _, string attr) => Eventos.Contains(attr);
}
```
Nota: verificar la firma exacta de la sobrecarga `XamlReader.Load(string, object)` en OpenSilver 3.3.3; si la pública solo expone `Load(string)`, usar `System.Xaml.XamlObjectWriter` con `XamlObjectWriterSettings { RootObjectInstance = pantalla }` (ambos están en `OpenSilver.dll`, confirmado) para aplicar sobre la instancia.

## Riesgos registrados en este plan

- **La sobrecarga `XamlReader.Load(string, object)` puede no ser pública en OpenSilver 3.3.3.** Alternativa concreta: usar `System.Xaml.XamlObjectWriter` con `XamlObjectWriterSettings.RootObjectInstance` (presentes en `OpenSilver.dll`, confirmado por decompilación) para aplicar el XAML sobre la instancia de la pantalla.
- **Los tests de UI de Task 6 pueden necesitar contexto WASM.** Alternativa: ejecutarlos en el proyecto E2E (WebKit) en lugar de xUnit puro.
- **Cargar librerías con `Assembly.Load(byte[])` bajo el intérprete WASM puede ser lento.** Se mide en Task 7; mitigación: cachear en memoria por sesión.
- **Conseguir los ensamblados de referencia de Silverlight 5 para compilar la app de prueba.** `build.md` fija la fuente (SDK de Silverlight 5); el `.xap` resultante se versiona para que el CI no dependa de ese SDK.
